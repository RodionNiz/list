## Двухсвязный список с фиктивным элементом
Программа содержит собственный двухсвязанный список, зацикленный с помощью фиктивного элемента. Данные о свободных элементах хранятся внутри списка с односторонней связью.

# Фичи
- **Закольцованность** - использование фиктивного элемента позволяет избежать дополнительных проверок.
- **Графический дамп** - многократно облегчает работу при поиске ошибок и отладке.
- **Бальшая вариативность функций работы с элементами** - 4 функции для вставки элемента в список и 5 для его извлечения

## Поддерживаемые команды

### Функции вставки элемента
* **InsertNext** - принимает в качестве параметра физический индекс элемента. Вставляет элемент на следующее логическое место. Не требует двухсвязанности.
* **InsertListLg** - принимает в качестве параметра логический индекс элемента. Вставляет элемент на следующее логическое место. Скорость работы пропорциональна логическому номеру.
* **InsertHead** - вставляет элемент на первое логическое место.
* **InsertTail** - вставляет элемент на последнее логическое место.


### Функции извлечения элемента
* **ExtrList** - принимает в качестве параметра физический индекс элемента и извлекает его.
* **ExtrListLg** - принимает в качестве параметра логический индекс элементаи извлекает его. Скорость работы пропорциональна логическому номеру.
* **ExtrNextLg** - принимает в качестве параметра логический индекс элементаи извлекает следующий логический элемент. Скорость работы пропорциональна логическому номеру. Не требует двухсвязанности.
* **ExtrHead** - извлекает элемент на первом логическом месте.
* **ExtrTail** - извлекает элемент на последнем логическом месте.
